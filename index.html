Hui Sub (David) Shim

PhD student, Electrical Engineering, Stanford University

I work on memory systems. DRAM has stopped getting cheaper per bit while memory has become the largest share of what a server costs, so I study what main memory should look like next and what an operating system has to do differently to use it. Before Stanford I spent nine years at Samsung building enterprise SSD firmware, which is where most of my intuitions about this come from.

I am advised by Philip Levis in the Stanford Information Networks Group.

Research

Memory is now the largest share of what a server costs and DRAM has stopped getting cheaper per bit, so my work is about what comes next and what the system software around it has to do differently. I am interested in denser memories whose constraints the kernel manages rather than the device hiding them, in how an operating system should place data once its memories are no longer alike, and in why packet processing at line rate spends so much of its memory bandwidth on copies it should not need.
